# 视频文件说明

## 喷射沉积锭坯设备 - 生产过程视频

请将生产过程视频文件命名为 `production-process.mp4` 并放置在此目录中。

### 视频要求：
- 文件名：`production-process.mp4`
- 格式：MP4（H.264编码）
- 建议分辨率：1920x1080 或 1280x720
- 建议时长：1-5分钟
- 文件大小：建议不超过50MB

### 使用位置：
该视频将显示在"喷射沉积锭坯设备"产品详情页面的"生产过程"部分。

### 临时解决方案：
如果暂时没有视频文件，可以：
1. 使用占位图片代替
2. 或在代码中注释掉视频部分，等有视频后再启用
