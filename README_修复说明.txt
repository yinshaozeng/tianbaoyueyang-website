📞 问题排查
================================================================================

Q: 修改后国家列表还是只显示中文？
A: 刷新浏览器或清除缓存。确保 npm run dev 已启动最新版本。

Q: 构建失败提示找不到 terser？
A: 运行 npm install terser -D 安装缺失的依赖。

Q: 如何添加新的国家/地区？
A: 在 src/utils/countries.js 添加国家代码，
   然后在 src/locales/index.js 的各语言中添加翻译。

Q: 如何添加新的语言？
A: 在 src/locales/index.js 中添加新语言对象，
   包含所有翻译键的翻译。
